**Alpha version: crashes, rendering problems, and other compatibility issues may still occur.**

This is a heavily modified version of touchHLE built around compatibility work for **The War of Eustrath HD** and now adds experimental support for **Rogue Planet**.

### Rogue Planet support

Support has been added for **Rogue Planet**.

So far, only the **beginning of the game** has been tested. During **mission 2**, some units may fail to render in the **battle close-up views**. This does not prevent the mission from being played, and the rendering issue was not observed in the following mission, where the units rendered normally.

The rest of Rogue Planet has **not yet been tested**, so additional compatibility issues, rendering bugs, crashes, or freezes may still be present later in the game.

The current tested Rogue Planet baseline is revision `32bd9200` (Android versionCode 15).

The game IPA is not included.
